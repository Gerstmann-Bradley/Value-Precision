# Value-Precision
A Blender add-on that allows you to input or modify values more precisely.

# Type Values
1. Hover your mouse to the socket and hit shortcut, by default as "`" (the button on the left of "1")

<img width="447" height="192" alt="image" src="https://github.com/user-attachments/assets/86d218a6-442b-4d3e-a3ec-15492b7cbf41" />

2. A window pop up. You can just type any values like 15. By default it runs on Division, and you can choose the exponent or precision.
3. You are able the preview the result you are going to enter. Space or LMB in other space will apply the value, or RMB will cancel the operation.

# Automatic Detection and overrides.

1.if the selected Socket has a value of 0.005, it has 3 decision, so the input value will by default considered in the precision of 10^3.

<img width="442" height="152" alt="image" src="https://github.com/user-attachments/assets/65d7c374-a023-427f-b600-beef714ab688" />

2. you can utilize the shortcut Z to decrease exponent or X to increase exponent (or precision) for the final values.

3. shortcut "C" will be used to switch operations between division and multiply.

All shortcuts are modifiable in the preferences

# Sliding Values

1. Hover your mouse to the socket and hold "Middle Mouse" to scroll.

2. It uses similar logic of detection and overrides. Additionally you can hold Shift to automatically slide with 1 more decimals.
